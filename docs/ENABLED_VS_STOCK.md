# Что дополнительно включено относительно заводской прошивки

Полный список того, что в текущей ветке `kobra2neo` включено/добавлено сверх
заводской прошивки (`stock/master`, Anycubic Kobra 2 Neo 1.5.6.3).

Проверено двумя независимыми способами:

1. Построчный разбор **всех** `#define` в `Marlin/Configuration.h` и
   `Marlin/Configuration_adv.h`: сравнивались состояния «включено/выключено»
   каждой опции у завода и в порте.
2. Сравнение таблиц символов обоих собранных образов
   (`arm-none-eabi-nm -C firmware.elf`): какие G-коды реально присутствуют в
   прошивке. Итог: `GcodeSuite::*` — 126 символов в порте против 129 у завода,
   единственное содержательное отличие — `G26`.

## 1. Дополнительные G-коды

| Команда | Что даёт | Чем включено |
|---|---|---|
| `G26` | Mesh Validation Pattern: печать тестового узора по сетке автоуровня | `#define G26_MESH_VALIDATION` |

Других команд, отсутствующих у завода, в образе нет. `M900` (Linear Advance),
`M48`, `M115`, `M420`, `M593`, `M430`, `M413` и т.п. присутствуют **в обоих**
образах. Команды `M108/M112/M410` у завода реализованы обычными обработчиками,
в порте — мгновенным `EMERGENCY_PARSER` (функционально доступны в обоих).

## 2. Дополнительные фичи и опции конфигурации

| Опция | Что включает | Примечание |
|---|---|---|
| `ENABLE_LEVELING_FADE_HEIGHT` | затухание компенсации сетки выше 10 мм | в upstream Marlin включена, завод выключил |
| `G26_MESH_VALIDATION` | `G26` (см. §1) | завод выключил |
| `SDCARD_SORT_ALPHA` | сортировка файлов на SD (`SDSORT_FOLDERS -1` — папки выше файлов) | `SDSORT_GCODE false`, команды `M34` нет |
| `SCROLL_LONG_FILENAMES` | прокрутка длинных имён файлов | влияет на штатный отрисовщик меню |
| `EMERGENCY_PARSER` | мгновенные `M108`/`M112`/`M410`, realtime-разбор | у завода выключен |
| `HOST_ACTION_COMMANDS` | уведомления/экшены хосту (старт/пауза/возобновление/отмена/финиш, `ACTION_ON_*`) | у завода выключен |
| `HOST_PROMPT_SUPPORT` | интерактивные промпты хосту (подтверждения, «продолжить») | включён под `HOST_ACTION_COMMANDS`; у завода выключен |
| `MEATPACK_ON_SERIAL_PORT_1` | сжатие протокола OctoPrint MeatPack на основном serial | у завода выключен; включён конфиг-коммитом порта. Без плагина обычный текстовый G-код работает как раньше |
| `PROBING_PART_COOLING_FAN` | новая опция порта: остановка/перезапуск part-fan вокруг точек проб | по умолчанию **включена** — повторяет заводское поведение (у завода вызовы безусловные); можно выключить |
| `PID_EDIT_MENU` | правка PID (`M301`/`M304`) в «Advanced Settings» | завод выключил; сами команды были и у завода |
| `PID_AUTOTUNE_MENU` | запуск автотюна PID (`M303`) из «Advanced Settings» | завод выключил; `M303` был и у завода |
| `SHAPING_MENU` | экран Input Shaping: частота/демпфирование X и Y (`M593`) | завод выключил; сами `INPUT_SHAPING_X/Y` были включены |

### Восстановленные пункты меню (завод держал их закомментированными)

| Пункт | Где | Что даёт |
|---|---|---|
| Store / Load Settings | More Config | `M500`/`M501` из экрана |
| Power Outage | More Config | тумблер Power-Loss Recovery (`M413`) |
| Preheat PLA / ABS | More Config | редактор пресетов (пишется в EEPROM) |
| Advanced Settings | More Config | дерево настроек Marlin: steps/mm, ускорения, PID, LA и т.д. |
| Input Shaping | More Config | экран частот/демпфирования X/Y (upstream-меню) |
| Advance K | More Config | правка Linear Advance K (пишется в EEPROM) |
| Mesh Viewer | More Config | **новый** экран порта: heatmap сетки 7×7 (BILINEAR) |

Все редактируемые значения (PID, Advance K, Input Shaping, пресеты)
сохраняются в EEPROM только через **Store Settings** (`M500`).

## 3. Что НЕ является дополнительно включённой фичей

Чтобы список был исчерпывающим — эти пункты проверены и добавлениями не являются:

- **Стандартные файлы меню Marlin** (`menu_backlash`, `menu_bed_tramming`,
  `menu_ubl`, `menu_tmc`, `menu_password` и т.д.) присутствуют в сборке, но
  соответствующие фичи (`BACKLASH_COMPENSATION`, `BED_TRAMMING`,
  `X_AXIS_TWIST_COMPENSATION`, `PASSWORD_FEATURE`, TMC и пр.) выключены в
  конфиге у обоих — код пустой/недоступен, поведения не меняет.
- **`M808` (repeat markers)**, **`M486` (cancel objects)** — в сборке есть
  объектные файлы, но фичи `GCODE_REPEAT_MARKERS` и `CANCEL_OBJECTS` выключены
  у обоих; символов команд в образе нет.
- **`M900`** — доступен и в заводской прошивке (символ `GcodeSuite::M900()`
  есть в обоих образах); распространённое утверждение, что завод вырезал M900,
  не подтверждается.
- **Шрифты, `utf8.cpp`, HAL-файлы TFT** — различия сборочного фильтра версий
  Marlin, не пользовательские фичи.
- **`DEFAULT_STEPPER_TIMEOUT_SEC 0`** — у завода то же самое
  (`DEFAULT_STEPPER_DEACTIVE_TIME 0`), таймаут выключения моторов не менялся.

## 4. Восстановлено как у завода (не добавление, а возврат к заводскому поведению)

Для полноты — то, что в порте приведено к заводу и не является фичей «сверх»:

- `M117` перезапускает таймер печати (A3).
- `EVENT_GCODE_SD_ABORT "G28XY\nM84"` — парковка XY и отключение моторов при
  остановке печати.
- Сброс позиции калибровочного модуля при `M502` (A14).
- `SD_FINISHED_RELEASECOMMAND "M84"`, `PARK_HEAD_ON_PAUSE`, LCD-сценарии паузы
  и завершения печати и т.д.

## 5. Отклонения от завода (изменённые значения, не «включено»)

- Сетка автоуровня **7×7** вместо заводской 5×5 (точнее уровень).
- `Z_PROBE_END_SCRIPT "G28XY"` без `M84` — чтобы `G29` в начале печати не
  помечал оси нехоженными (в остальном поведение как у завода).
- `DEBUG_LEVELING_FEATURE` выключен (завод включал — это отладочный режим,
  экономия flash/PROGMEM).

## 6. Как воспроизвести проверку

```bash
# 1) Конфиги: включено у нас, выключено у завода; и наоборот
git diff stock/master kobra2neo -- Marlin/Configuration.h Marlin/Configuration_adv.h

# 2) Реальные G-коды в образах (нужны firmware.elf обоих билдов)
arm-none-eabi-nm -C --defined-only .pio/build/ac_tri_f1/firmware.elf \
  | grep 'GcodeSuite::[GMT][0-9]' | sort > /tmp/port.gcodes
arm-none-eabi-nm -C --defined-only _ref/stock-build/.pio/build/ac_tri_f1/firmware.elf \
  | grep 'GcodeSuite::[GMT][0-9]' | sort > /tmp/stock.gcodes
diff /tmp/stock.gcodes /tmp/port.gcodes
```
